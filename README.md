# VIZARD

Чат со сквозным шифрованием. Ключ = комната: сервер видит только шифртекст и непрозрачный id комнаты.

## Запуск
```
npm install
npm start          # PORT=8080
npm test           # серверные тесты
```

## Что внутри
- **Ссылка-приглашение** `https://сайт/#k=КЛЮЧ`: ключ после `#` не уходит на сервер и сразу убирается из адресной строки.
- **Случайный ключ** (125 бит) по кнопке «создать новый».
- **Защита от ботов**: proof-of-work (SHA-256) на каждое подключение, сложность растёт для IP, которые часто просят задание.
- **Лимит подбора ключей**: не больше 12 разных комнат с одного IP за 10 минут, затем бан 5 мин, 10, 20 ... до суток.
- **Фото и голосовые**: сжимаются на устройстве (WebP ≤1280 px / Opus ~20 кбит/с), шифруются, на сервере лежат только шифрованные блобы (TTL 7 дней, квоты).
- **Текст** сжимается deflate до шифрования.
- **Удаление**: «Удалить чат для всех» стирает сообщения и файлы комнаты на сервере и кеш на устройствах участников.
- **Метаданные**: время хранится с точностью до минуты, IP нигде не сохраняется (только в памяти для лимитов), ключ и id не попадают в URL.
- **Кеш**: код ревалидируется по ETag (304), шифрованные медиа лежат в Cache Storage и стираются вместе с чатом.

## Переменные окружения (все необязательные)
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `IP_MODE` | `cf` на Render, иначе `socket` | как определять IP клиента: `cf`, `xff`, `socket` |
| `IP_HOPS` | 1 | для `xff`: сколько прокси справа доверяем |
| `POW_BITS` | 14 | сложность proof-of-work (0 = выключено) |
| `ROOM_GUESS_MAX` | 12 | разных комнат с одного IP за 10 мин |
| `MAX_ROOMS` | 500 | всего комнат |
| `MESSAGE_TTL_DAYS` / `MEDIA_TTL_DAYS` | 30 / 7 | срок хранения |
| `MAX_BLOB_KB` / `ROOM_MEDIA_MB` / `MEDIA_MB` | 600 / 40 / 200 | лимиты медиа |
| `DB_MAX_MB` | 400 | потолок размера базы |
| `ROOM_SALT`, `POW_SECRET` | встроенная / случайный | постоянные секреты |
| `ALLOWED_ORIGINS` | пусто | доп. разрешённые Origin для WebSocket |

На бесплатном Render диск эфемерный: история и медиа пропадают при перезапуске.
